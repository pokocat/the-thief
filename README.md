# 怪盗塔防 · Heist TD

一个**原创** 3D 卡通奇幻塔防原型（MVP），灵感来自经典 RTS 自定义地图的「经济滚雪球型小偷塔防」，但**不使用任何受版权保护的原游戏模型、贴图、图标、音效、名称或精确数值**。所有 3D 美术均由代码程序化生成（低多边形几何 + 程序材质），零外部资源。

核心特色：建造并升级**怪盗塔**，攻击怪物时**偷取金币**，用偷来的钱研究科技、补防空、堆英雄，守住 **30 波**怪物。

## 技术栈

- **Babylon.js 7** + **TypeScript** + **Vite**
- 全部美术程序化生成（无二进制资源 → 天然原创、无版权风险、体积小）
- 手机浏览器 / PC 浏览器即开即玩

## 运行

```bash
npm install
npm run dev        # 开发服务器，浏览器打开提示的地址
npm run build      # 生产构建到 dist/
npm run preview    # 预览生产构建

npm run typecheck  # 仅类型检查
npm run smoke      # 无头(NullEngine)跑通 30 波并验证胜利
npm run smoke:lose # 无头验证漏怪 20 → 失败
```

`npm run smoke` 用 Babylon `NullEngine` 在无 GPU/无浏览器环境下跑完整玩法循环
（建塔 → 出怪 → 移动 → 攻击 → 偷钱 → 击杀 → 胜/负），用于 CI 与回归。

## 操作

- **点击发光台座**：打开建造菜单（怪盗 / 法师×3 / 冰霜 / 弓箭 / 英雄）。
- **点击已建塔**：查看属性、升级、切换索敌、出售；英雄塔可买装备。
- **拖动**：平移视角。**滚轮 / 双指捏合**：缩放。**🎯 视角**：复位。
- **📜 科技**：打开科技面板（5 项，各 5 级，升级立即影响已建塔）。
- **下一波**：立即开波（否则倒计时自动开波）。

## 玩法循环

怪物沿固定路径从传送门走向水晶核心 → 你在台座建塔 → 塔自动攻击 →
怪盗塔每攻击 `stealEveryHits` 次偷一次金币（每只怪被同塔最多偷 `maxStealPerEnemyPerTower` 次）→
击杀给金币、波末给奖励、Boss 给额外金币 → 守住 30 波且漏怪 < 20 即**胜利**，漏怪达 20 即**失败**。

偷钱公式（全部来自配置）：
`steal = (stealBaseFlat + wave * stealPerWave) * tower.stealMultiplier * enemy.valueMultiplier`

## 配置化

所有数值都在 `src/config/*.json`，逻辑层不硬编码：

| 文件 | 内容 |
|---|---|
| `balance.json` | 初始金币、漏怪上限、偷钱公式系数、对象数上限、速度缩放等 |
| `towers.json` | 5 类塔（怪盗升级链 5 级、法师 3 种、冰霜、弓箭、英雄）+ 特效参数 |
| `enemies.json` | 普通/高速/重甲/高血/空军/魔抗/低收益/偷钱怪/Boss/终局Boss |
| `waves.json` | 30 波（含混合波 `groups`、Boss 额外金币、提示文案） |
| `tech.json` | 5 项科技 × 5 级 + 价格曲线 |
| `items.json` | 5 件英雄装备 |
| `map.json` | 路径点、建造点、出怪口、终点、地图边界 |

改完保存即生效，便于数值调试。

## 项目结构

```
src/
├─ main.ts                 入口
├─ bjs.ts                  Babylon 再导出
├─ config/                 全部数值配置 (JSON) + 类型 + 加载器
├─ core/                   Game 主循环 / 状态 / 事件总线 / 对象池 / 相机
├─ map/                    路径系统 / 场景构建（浮岛·石路·装饰·传送门·水晶）
├─ entities/               Enemy / Tower 及其 Manager + 程序化模型工厂
├─ systems/                波次 / 战斗 / 索敌 / 偷钱 / 科技 / 装备 / 特效
└─ ui/                     HUD / 建造菜单 / 塔面板 / 科技面板 / 结算 / 世界叠加层
```

## 主要模块

- **Game**：固定步长（1/60）更新 + 渲染；点击拾取分发到 UI。
- **PathSystem**：按距离沿折线插值移动，速度一致。
- **WaveSystem**：30 波，组内并行时间线，自动开波倒计时，胜负判定，逐波统计。
- **EnemyManager / Enemy**：池化、状态效果（减速/冰冻/破甲，含 Boss 控制抗性）、死亡动画、漏怪与偷钱怪扣金。
- **TowerManager / Tower**：建造/升级/出售、嗜血光环、装备、有效属性（科技+光环+装备实时计算）。
- **Targeting / Combat / Steal**：first/nearest/strongest 索敌；护甲(物理) / 魔抗(魔法)减伤；偷钱与上限。
- **EffectSystem / WorldOverlay**：池化弹道/暴击/破甲/冰冻/偷钱金币，投影血条与浮字（击杀/偷钱/扣金不同样式）。

## 性能

- 对象池：怪物、子弹、特效、金币、浮字、血条全部复用。
- 共享缓存材质（按颜色去重），低模几何。
- 同屏怪物上限可配置（默认 60），波次按上限节流出怪。
- 固定步长逻辑 + 每帧投影叠加层。

> 注：当前为快速验证使用 Babylon 聚合包，打包体积较大（~1.1MB gzip）。后续可改为按需 import 树摇以减小体积。

## 视角

固定 3/4 斜俯视（pitch≈45°、azimuth≈38°），支持缩放/平移/复位；旋转已在架构中预留（`CameraController` 保留 alpha/beta），后续可一键开启自由旋转。
